------------------------------------------------------------------------
Components Delivered
------------------------------------------------------------------------

Core Pipeline
  - BabelGenerator       thalos_prime/lob_babel_generator.py
                         Deterministic page generation from hexadecimal addresses.
                         Uses the Basile algorithm (29-char alphabet, 3200-char pages).

  - BabelEnumerator      thalos_prime/lob_babel_enumerator.py
                         Query-to-address mapping via n-gram extraction and seeded hashing.

  - BabelDecoder         thalos_prime/lob_decoder.py
                         Multi-metric coherence scoring: language density, structure,
                         n-gram patterns, and exact-match. Rule-based normalization
                         with optional LLM provider fallback.

Control Plane
  - ControlPlane         thalos_prime.py
                         Orchestrates the full lifecycle: initialize → validate →
                         operate → reconcile → checkpoint → terminate.

Authentication
  - APIKeyAuthenticator  thalos_prime/auth/api_key.py
                         Lifecycle-managed API key auth. Loads keys from
                         THALOS_API_KEYS env var. Supports THALOS_AUTH_DISABLED=1
                         bypass. Raises DeterministicHalt on misconfiguration.
                         FastAPI Depends() integration included.

Cache
  - TTLCache             thalos_prime/cache/ttl_cache.py
                         Generic in-memory TTL cache (K, V). Bounded by max_size,
                         expires entries after ttl_seconds. Replaces ad-hoc
                         _SEARCH_CACHE dict. Full lifecycle management.

Database (Persistence)
  - ResultStore          thalos_prime/database/store.py
                         SQLite-backed persistence for search results and sessions.
                         Stdlib sqlite3 only — no external dependencies.
                         PRAGMA integrity_check on reconcile().

  - DatabaseManager      thalos_prime/database/connection.py
                         SQLAlchemy connection pool (optional ORM feature).

Workers
  - BatchProcessor       thalos_prime/workers/batch_processor.py
                         Deterministic batch worker for background page processing.
                         FIFO queue via collections.deque. Seeded for replay.
                         Results sorted by coherence score descending.

API Server
  - FastAPI server       thalos_prime/api/server.py
                         REST API with routes: /chat, /search, /generate,
                         /enumerate, /decode, /admin. Raises RuntimeError
                         on route import failure (no silent degradation).

  - Admin routes         thalos_prime/api/routes/admin.py
                         System status, metrics, cache clear, session cleanup,
                         config inspection, and graceful SIGTERM shutdown.

  - Decode routes        thalos_prime/api/routes/decode.py
                         Coherence scoring, batch decode, weight update.
                         Returns HTTP 501 when LLM mode is requested without
                         a configured provider.

CLI
  - CLI commands         thalos_prime/cli/commands.py
                         argparse subcommands: generate, enumerate, decode,
                         search, serve. Delegates to real pipeline modules.
                         Entry point: thalos_prime.cli.commands.run_cli().

  - Legacy CLI           src/thalosprime/cli.py
                         Delegates to thalos_prime.cli.commands.run_cli().

Deployment Options
------------------------------------------------------------------------

Python package (development install):
  pip install -e ".[dev]"
  python run_thalos.py

Docker:
  docker build -t thalos-prime .
  docker run -p 8000:8000 thalos-prime

Docker Compose:
  docker-compose up

Standalone server:
  python -m uvicorn thalos_prime.api.server:app --host 0.0.0.0 --port 8000

CLI:
  thalos-prime search --query "hello world" --max-results 5
  thalos-prime generate --address abc123
  thalos-prime serve --host 0.0.0.0 --port 8000

Key Environment Variables
------------------------------------------------------------------------

THALOS_LIBRARY_PATH   Path to local library (optional)
THALOS_API_KEYS       Comma-separated allowed API keys
THALOS_AUTH_DISABLED  Set to 1 to bypass API key enforcement
THALOS_ADMIN_API_KEY  Admin API key for /admin/* routes
