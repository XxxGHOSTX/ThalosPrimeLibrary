    Getting Started

    Thalos Prime is a symbiotic intelligence framework that extracts coherent information from high-entropy data spaces. All advanced capabilities are always-on — no manual flags required.

    Features

    • Console: Interactive chat interface for queries
    • Pipeline: Full end-to-end query → enumerate → generate → score → synthesize visual pipeline
    • Search: Advanced adaptive search with automatic optimization, diversity reranking, and query expansion
    • Generate: Deterministic page generation from addresses
    • Enumerate: Query-to-address mapping
    • Decode: Coherence analysis and scoring
    • Workers: Background worker status — coherence floor enforcement, benchmarking, audit health

    Always-On Background Processes

    • Adaptive Search: Intent-aware optimization active on all searches by default
    • Coherence Floor Enforcement: Minimum 79.0 score enforced every 2 minutes
    • Benchmark Reporter: Regression benchmarks run every 30 minutes
    • Audit Health Check: Audit trail verified every 5 minutes
    • Cache Warm: Top queries pre-warmed every 10 minutes
    • Index Refresh: Stale cache evicted every 5 minutes
