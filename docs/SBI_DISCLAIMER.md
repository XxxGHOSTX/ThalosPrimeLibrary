# SBI (Symbiotic Biological Intelligence) — Software Architecture Disclaimer

## Important Notice

**Thalos Prime is a pure software system. It does not integrate with biological cells, human neural tissue, or any physical wetware substrate.**

---

## What "SBI" Means in This Project

The term **SBI (Symbiotic Biological Intelligence)** is used in this repository as a **software architecture metaphor**. It describes how software components cooperate with each other in a mutually reinforcing ("symbiotic") way to achieve coherent outcomes — in software only.

Specifically:
- "Symbiotic" describes cooperative software component relationships, not biological symbiosis.
- "Biological" is a metaphorical label for the NEXUS module architecture (nucleus, lysosome, membrane, mitochondria, cytoplasm, ER) — these are named after cellular organelles as a design metaphor only.
- "Intelligence" refers to software-based reasoning, planning, and constraint-solving logic.
